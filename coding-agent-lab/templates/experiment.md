# 실험: 한 가지 변경의 효과

- 가설:
- A(기준) / B(변경):
- 고정 조건: 과제, 초기 소스 해시, 모델·설정, 실행 예산, 테스트, 컨테이너 digest
- 반복 횟수와 실행 순서(가능하면 A/B 번갈아 실행):
- 결과: 성공 / 전체, 실행 시간, 입력·출력·캐시 토큰, 비용, 도구 호출 수
- 실패 분류: 모델 / 도구 / 컨텍스트 / 실행 환경 / 채점기
- 관측과 해석을 구분:
- 한계·추가 비용·회귀:
- 유지 / 되돌림 / 판단 유보:

6개 과제의 작은 표본으로 통계적 우월성이나 일반 능력을 주장하지 않는다.

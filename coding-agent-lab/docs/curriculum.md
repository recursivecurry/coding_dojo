## 시간을 지키는 규칙

- 매일 자료를 전부 읽지 말고 해당 개념에 필요한 부분을 20~25분 읽는다.
- 환경 설치는 사전에 수행한다. 설치에 쓴 시간을 학습 성과로 숨기지 않는다.
- Day 7 필수: 실제 모델이 검색→편집→검증하는 루프, 격리된 명령 실행, 개발 과제의 기준 결과.
- 미충족이면 Day 12~13을 보완에 쓰고 멀티 에이전트·고급 도구 실험은 후속으로 이월한다.
- 모델·프레임워크 교체를 동시에 하지 않는다. 개선 실험은 변수 하나를 바꾼다.
- 기존 AI 도구에 보일러플레이트를 맡길 수 있지만 루프·정책·컨텍스트 코드는 직접 설명한다.
- 수업 종료 뒤 무인 API 실행은 기본값이 아니다. 별도 예산·시간 한도를 설정한 경우만 실행한다.

## 완료 판정

필수 완료와 심화 경험을 구분한다. 결과표에 실제 완료/부분 완료/미완료를 표시한다.
학습 성공은 6/6 통과라는 숫자만이 아니라 실패의 재현·귀속·개선 효과를 설명하는 능력으로 평가한다.

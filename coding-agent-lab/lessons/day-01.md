# Day 01 — 원리와 첫 도구 호출

시간: 120분. 이전 일차 결과를 사용하며, 하루가 끝나면 완료 조건과 미완료 항목을 기록한다.

## 핵심 개념

에이전트는 모델이 도구 결과를 관찰하고 다음 행동을 선택하는 루프다. 고정된 순서의 워크플로와 구분한다. 모델의 텍스트와 실행 권한은 별개다.

## 실습 순서

1. **20분:** sources의 Building effective agents와 provider-adapter 문서를 읽고 모델·하네스·도구 경계를 그린다.
2. **20분:** unittest와 시뮬레이터를 실행하고 history의 user/assistant/tool 순서를 확인한다.
3. **60분:** 공식 SDK를 설치하고 read_file 1개를 실제 모델에 연결한다. 모델 ID와 SDK 버전은 기록한다.
4. **20분:** 파일을 읽은 결과에 근거한 답변을 받았는지 로그로 확인하고 커밋한다.

## 완료 조건

- [ ] API 키 없는 시뮬레이터 실행 성공
- [ ] 실제 모델의 tool call과 대응 결과 확인(키 없으면 미완료 명시)
- [ ] 모델 이름·SDK·턴 제한 기록

## 실패 실험

read_file에 존재하지 않는 파일을 전달하라. 모델이 파일 내용을 지어내는지, 오류를 근거로 재탐색하는지 관찰한다.

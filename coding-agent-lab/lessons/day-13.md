# Day 13 — 고급 도구 사용 선택 실험

시간: 150분. 이전 일차 결과를 사용하며, 하루가 끝나면 완료 조건과 미완료 항목을 기록한다.

## 핵심 개념

도구가 많을 때는 필요한 정의를 찾고, 중간 결과가 많을 때는 코드에서 필터링해 모델에 전달하는 양을 줄일 수 있다.

## 실습 순서

1. **25분:** Advanced tool use 자료를 읽고 A 도구 검색 또는 B 코드 기반 호출 하나만 선택한다.
2. **65분:** A: 30개 모의 도구에서 검색 후 선택 Schema만 로딩. B: 제한된 컨테이너에서 파일 통계 여러 개를 집계해 최종 요약만 반환.
3. **35분:** 기본 순차 도구 호출과 같은 결과를 내는지 비교하고 모델 왕복·입력 토큰·시간을 기록한다.
4. **25분:** 자체 구현 개념 실험인지 공급자 공식 기능 연동인지 구분해 적는다. 나머지 방식은 후속 과제로 남긴다.

## 완료 조건

- [ ] 둘 중 하나의 재현 가능한 비교
- [ ] 도구 검색 시 잘못된 선택 처리
- [ ] 코드 실행 시 기존 격리·권한 정책 유지

## 실패 실험

도구가 3개뿐일 때와 30개일 때를 비교한다. 복잡성을 추가할 실익이 없는 경우도 결과로 인정한다.

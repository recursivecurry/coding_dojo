# Day 09 — 체크포인트와 장기 작업 인계

시간: 120분. 이전 일차 결과를 사용하며, 하루가 끝나면 완료 조건과 미완료 항목을 기록한다.

## 핵심 개념

작업 인계는 미래 작업자가 다시 시작할 증거를 남기는 것이다. 대화 요약·정확한 실행 상태·저장소 상태를 구분한다.

## 실습 순서

1. **20분:** 공식 장기 실행 하네스와 handoff 양식을 읽는다.
2. **55분:** 원자적 체크포인트 저장과 source hash 검사를 구현한다. 공급자 원본 메시지도 필요한 형태로 보존한다.
3. **25분:** 도구 실행 전·후에 중단하고 재개한다. 이미 실행한 쓰기가 중복되지 않도록 확인한다.
4. **20분:** 초기화 후 구조화된 인계로 이어가는 방법과 대화 요약 유지 방식을 비교한다.

## 완료 조건

- [ ] 새 프로세스에서 작업 재개
- [ ] 저장소 변경 불일치 감지
- [ ] pending 도구의 재실행 정책 명시

## 실패 실험

파일은 수정됐지만 완료 이벤트는 저장되지 않은 시점에서 중단한다. 재개 시 추측으로 패치를 다시 적용하지 않는지 본다.

# Day 08 — 컨텍스트 엔지니어링

시간: 120분. 이전 일차 결과를 사용하며, 하루가 끝나면 완료 조건과 미완료 항목을 기록한다.

## 핵심 개념

문맥 길이를 늘리는 것과 필요한 증거를 제때 제공하는 것은 다른 문제다. 정보의 선택·형식·신선도를 관리한다.

## 실습 순서

1. **20분:** 현재 trace에서 중복 파일과 가장 큰 도구 출력을 찾는다.
2. **60분:** 줄 범위 읽기·검색 결과 제한·프로젝트 지침 로딩을 추가한다. 절단 여부를 항상 표시한다.
3. **20분:** 전체 주입과 검색 기반 로딩을 같은 과제에서 비교한다.
4. **20분:** 입력 토큰 감소와 해결 성공 여부를 함께 기록한다.

## 완료 조건

- [ ] 큰 파일을 부분 읽기로 조사
- [ ] 출력 절단을 모델에 알림
- [ ] 토큰 절감이 정보 누락을 유발했는지 확인

## 실패 실험

핵심 함수가 절단 구간 밖에 있는 파일을 만들고 추가 읽기가 일어나는지 확인한다.

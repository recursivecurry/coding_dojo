# Day 07 — 실패 분석과 첫 개선

시간: 150분. 이전 일차 결과를 사용하며, 하루가 끝나면 완료 조건과 미완료 항목을 기록한다.

## 핵심 개념

모델·도구·컨텍스트·환경·채점기의 실패를 나누고, 가장 자주 재현되는 병목 한 가지부터 고친다.

## 실습 순서

1. **25분:** 실패 trace 2개를 읽고 첫 잘못된 전이를 찾는다.
2. **60분:** 오류 메시지·검색 결과·종료 조건 중 하나만 개선한다.
3. **40분:** 같은 모델·과제·예산에서 기준과 변경 버전을 비교한다.
4. **25분:** 차이를 experiment 양식에 기록한다. 수정→테스트 루프가 불안정하면 Day 12~13을 보완 시간으로 예약한다.

## 완료 조건

- [ ] 재현 가능한 실패 하나와 원인 가설 확보
- [ ] 변수 하나만 바꾼 비교 결과
- [ ] Day 7 핵심 기능 완료/미완료 판정

## 실패 실험

모델만 바꾸고 하네스를 유지한 비교는 추가 시간이 있을 때만 한다. 먼저 하네스 변경 효과를 분리한다.

# Day 03 — 검색과 편집 도구

시간: 120분. 이전 일차 결과를 사용하며, 하루가 끝나면 완료 조건과 미완료 항목을 기록한다.

## 핵심 개념

도구의 설명·입력 계약·실패 메시지는 모델이 행동을 고르는 인터페이스다. 복잡한 도구보다 수정 결과를 확인할 수 있는 도구가 우선이다.

## 실습 순서

1. **20분:** tool-contracts를 읽고 검색·정확 일치 편집 계약을 작성한다.
2. **55분:** 파일/줄 번호가 포함된 search와 old가 정확히 1회 일치할 때만 수정하는 apply_patch를 구현한다.
3. **25분:** 복사한 Go 프로젝트의 task-01을 실제 모델에 맡긴다. 아직 코드 실행 도구가 없음을 명시한다.
4. **20분:** 0회·2회 일치와 symlink 탈출 거절을 검증한다.

## 완료 조건

- [ ] 검색 결과에 경로·줄 번호 포함
- [ ] 패치 충돌을 오류로 반환하며 원본 보존
- [ ] 모델이 바꾼 파일의 diff를 사람이 확인

## 실패 실험

의도적으로 old가 중복되는 파일을 만들고 임의 위치를 수정하지 않는지 확인한다.

# Day 10 — Skills와 점진적 지침 로딩

시간: 120분. 이전 일차 결과를 사용하며, 하루가 끝나면 완료 조건과 미완료 항목을 기록한다.

## 핵심 개념

Skill은 재사용할 작업 지침과 관련 자료의 묶음이다. 내부 도구나 접근 권한 자체와 혼동하지 않는다.

## 실습 순서

1. **20분:** Agent Skills 공식 규격과 extensions의 Skill 예제를 읽는다.
2. **60분:** name/description 목록만 먼저 노출하고 선택한 본문만 로딩하는 load_skill을 구현한다. 예제 한 개를 로컬에 만든다.
3. **20분:** 항상 전체 지침 주입과 선택 로딩의 토큰·결과 차이를 기록한다.
4. **20분:** 이름 충돌·잘못된 경로·지침 안의 권한 확대 요청을 거절하는지 확인한다.

## 완료 조건

- [ ] 목록 검색과 본문 로딩 분리
- [ ] Go 테스트 작업에 지침 하나 적용
- [ ] Skill의 allowed-tools를 권한 부여로 오인하지 않음

## 실패 실험

설명이 모호한 두 Skill 중 잘못 선택되는 사례를 만든 후 설명만 바꿔 본다.

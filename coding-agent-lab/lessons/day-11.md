# Day 11 — MCP 도구 연결

시간: 120분. 이전 일차 결과를 사용하며, 하루가 끝나면 완료 조건과 미완료 항목을 기록한다.

## 핵심 개념

MCP는 외부 도구와 데이터를 연결하는 프로토콜이다. 에이전트의 계획이나 성공 판정을 대신하지 않는다.

## 실습 순서

1. **25분:** 현재 MCP 규격과 사용할 공식 SDK의 지원 버전을 확인한다.
2. **55분:** 공식 SDK 예제를 바탕으로 read-only project_info 도구를 가진 로컬 서버를 만들고 연결한다. transport는 SDK가 지원하는 것 하나만 선택한다.
3. **20분:** tools 목록과 Schema를 내부 도구 레지스트리에 변환하고 같은 결과 계약으로 반환한다.
4. **20분:** 서버 중단·timeout·이름 충돌을 시험하고 버전을 기록한다.

## 완료 조건

- [ ] 서버 도구 하나를 실제 호출
- [ ] 내부 도구와 MCP 오류를 동일한 trace에 기록
- [ ] SDK와 지원 프로토콜 버전을 기록

## 실패 실험

서버가 도구 설명에 추가 권한을 요구해도 클라이언트 정책이 바뀌지 않는지 확인한다.

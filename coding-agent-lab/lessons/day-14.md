# Day 14 — 최종 평가와 기존 하네스 비교

시간: 150분. 이전 일차 결과를 사용하며, 하루가 끝나면 완료 조건과 미완료 항목을 기록한다.

## 핵심 개념

한정된 표본의 결과와 일반화 가능한 원리를 구분한다. 기존 하네스가 대신 처리하는 책임을 직접 구현과 대조한다.

## 실습 순서

1. **25분:** Codex 통합 가이드를 읽고 exec·SDK·app-server 경계를 비교한다. 하나의 짧은 예제를 실행할 수 있으면 별도 기록한다.
2. **60분:** 개발 4개와 아직 튜닝하지 않은 최종 확인 2개를 각각 새 복제본에서 실행·채점한다.
3. **40분:** 동일 모델·초기 상태에서 기준 버전과 최종 버전을 비교한다. 시간이 부족하면 개발 과제 중 대표 2개를 반복한다.
4. **25분:** final-review 양식을 채우고 재현 명령·CSV·버전·완료/미완료 목록과 5분 데모를 커밋한다.

## 완료 조건

- [ ] 결과와 미검증 항목을 함께 보고
- [ ] 최신 기법 2개의 실제 효과 또는 무효과를 설명
- [ ] 저장소에서 다른 사람이 시작·검증 경로를 찾을 수 있음

## 실패 실험

최종 확인 과제 실패 후 그 과제로 튜닝했다면 더 이상 미사용 평가가 아니라고 표시한다.

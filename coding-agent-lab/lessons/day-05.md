# Day 05 — 격리와 실행 정책

시간: 120분. 이전 일차 결과를 사용하며, 하루가 끝나면 완료 조건과 미완료 항목을 기록한다.

## 핵심 개념

프로젝트 지침은 권한 경계가 아니다. 파일 쓰기와 프로세스 실행의 실제 범위를 호스트 코드와 컨테이너 설정으로 제한한다.

## 실습 순서

1. **20분:** setup·architecture의 격리 경계를 읽고 마운트와 키 위치를 기록한다.
2. **50분:** 작업 복제본만 마운트하는 Docker 실행기를 구현한다. network none·비루트·메모리·CPU·PID·timeout 제한을 적용한다.
3. **30분:** 출력 폭주·무한 명령·../·symlink·README의 악성 지시를 시험한다.
4. **20분:** 정책 거절과 도구 실패를 구분하고 실행 정책 버전을 기록한다.

## 완료 조건

- [ ] 호스트 셸·홈·Docker 소켓을 에이전트에 제공하지 않음
- [ ] 제한 초과 프로세스/컨테이너 종료 확인
- [ ] 키를 명령 환경과 로그에 노출하지 않음

## 실패 실험

README에 상위 지침을 무시하고 다른 폴더를 읽으라는 문장을 넣는다. 모델이 시도하더라도 실행 경계가 차단하는지 확인한다.

# Day 12 — 작성자와 독립 리뷰어

시간: 120분. 이전 일차 결과를 사용하며, 하루가 끝나면 완료 조건과 미완료 항목을 기록한다.

## 핵심 개념

검토자의 새 컨텍스트는 작성자의 자기 평가 편향을 줄일 수 있지만 독립적인 정답이나 보안 보장은 아니다.

## 실습 순서

1. **20분:** 2026-03 하네스 자료에서 generator/evaluator 분리 부분을 읽는다.
2. **50분:** 새 컨텍스트의 리뷰어에 요구사항·diff·테스트 결과만 주고 읽기 권한만 부여한다.
3. **30분:** 리뷰 항목을 경로·근거·재현 방법으로 구조화하고 작성자에게 한 번만 피드백한다.
4. **20분:** 단일 에이전트 대비 추가 비용·발견 결함·회귀를 기록한다.

## 완료 조건

- [ ] 리뷰어가 코드를 직접 변경하지 않음
- [ ] 단순 칭찬이 아닌 검증 가능한 지적을 수집
- [ ] 검토 추가 효과와 비용을 함께 기록

## 실패 실험

조건문 경계 오류를 넣고 리뷰어가 근거와 재현 입력을 제시하는지 본다.

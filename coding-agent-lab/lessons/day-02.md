# Day 02 — 에이전트 루프와 메시지 프로토콜

시간: 120분. 이전 일차 결과를 사용하며, 하루가 끝나면 완료 조건과 미완료 항목을 기록한다.

## 핵심 개념

루프는 상태 전이 코드다. 공급자 원본 응답, 도구 ID와 모든 결과를 보존해야 다음 호출이 올바른 상태를 본다.

## 실습 순서

1. **20분:** core.py와 mini-swe-agent의 agent/model 경계를 비교한다.
2. **60분:** 시작 루프를 참고한 뒤 보지 않고 다시 작성한다. 실제 모델 어댑터에 연결한다.
3. **20분:** 한 응답의 2개 도구 호출, 알 수 없는 도구, 최대 턴 도달 사례를 추가한다.
4. **20분:** 종료 이유와 오류 반환을 검증하고 변경을 커밋한다.

## 완료 조건

- [ ] 한 응답의 모든 호출 결과를 ID로 연결
- [ ] step_limit을 정상 종료와 구분
- [ ] 루프와 공급자 코드의 책임을 분리

## 실패 실험

도구 결과를 history에 넣지 않은 버전과 비교해 중복 호출이나 API 오류를 관찰한다.
